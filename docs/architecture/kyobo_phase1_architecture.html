⚠ Phase 1 의도적 제약 — 이유가 있는 단순함
Phase 1 NFT는 블록체인 도장을 찍는 증명서에 가깝다. 온체인 로직(Solidity)은 mint/burn/transfer 표준 함수뿐이며, 모든 비즈니스 로직은 당사 내부 서버에 존재한다.
제약 이유: ① VASP 인가 부재 → 직접 TX 서명·브로드캐스트 불가  ② 기술 내재화 시간 필요  ③ 규제 불확실성 → 외부 업체 위탁으로 리스크 분산
Phase 2/3에서 VASP 인가 + 자체 컨트랙트 배포 + 직접 Custody 전환으로 단계적 내재화 예정.
