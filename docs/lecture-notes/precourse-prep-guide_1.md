### 트랙 B — JS 흐릿함, JS+TS 둘 다 (6시간)

권장 순서 (위에서 아래로):

**1단계. 모던 JavaScript 튜토리얼 — 파트 1 핵심만 (4시간)**
- 사이트: **https://ko.javascript.info/**
- 한국어로 가장 잘 정리된 무료 자료
- *모두 읽지 마시고* 아래 챕터만:
  - **변수와 자료형**: `let`, `const`, 자료형, 형 변환
  - **연산자**: 비교, 논리, 일반
  - **함수**: 함수 선언, 함수 표현식, 화살표 함수
  - **객체**: 객체 기본, 메서드와 `this`, 옵셔널 체이닝
  - **배열과 메서드**: 배열, `map`, `filter`, `forEach`
  - **Promise와 async/await**: 콜백, Promise, async/await
- **소요: 4시간** (보시는 속도에 따라 조정)

**2단계. 핸드아웃 (1시간)**
- 강의 자료 *TypeScript 워밍업 핸드아웃* 1~8장
- **소요: 1시간**

**3단계. 짧은 코드 작성 (1시간)**
- 본인 컴퓨터에 Node.js 설치 (https://nodejs.org/, LTS 버전)
- 터미널에서 `node` 입력 후 다음 시도:

```javascript
// 시도해보기 1: 변수와 함수
const greet = (name) => `Hello, ${name}!`;
console.log(greet("World"));

// 시도해보기 2: 배열 처리
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);
console.log(doubled);  // [2, 4, 6, 8, 10]

// 시도해보기 3: async/await
async function fetchData() {
  const res = await fetch("https://jsonplaceholder.typicode.com/users/1");
  const data = await res.json();
  return data;
}
fetchData().then(data => console.log(data.name));
```

- 위 3개 코드를 *직접 실행*해보시면 첫 날 따라가기 훨씬 수월합니다.
- **소요: 1시간**

**총 6시간**
