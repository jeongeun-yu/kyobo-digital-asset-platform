# 실습 전 사전 준비 가이드

본 교육의 원활한 진행을 위해 교육 시작 전 아래 사항을 반드시 완료해 주시기 바랍니다.

---

## 1. Ethereum 개인 지갑 준비

실습 시 스마트 컨트랙트 상호작용 및 트랜잭션 전송을 위해 필요합니다.

- **준비 사항**: Ethereum 키페어(주소 및 프라이빗 키) 생성
- **권장 도구**: MetaMask(메타마스크) 설치 및 지갑 생성
  - Chrome 웹스토어 → "MetaMask" 검색 → 설치
  - 새 지갑 생성 → 비밀복구구문(12단어) 안전하게 보관

> **주의**: 실습용 계정은 가급적 새 계정을 생성하여 사용하는 것을 권장합니다.  
> 기존에 실제 자산이 있는 지갑은 사용하지 마세요.

---

## 2. Sepolia 테스트넷 이더(ETH) 수령

실습 네트워크인 Sepolia에서 사용할 가스비(수수료)를 미리 확보해야 합니다. (약 0.1 ETH 이상 권장)

**수령 방법**: 아래 파우셋(Faucet) 사이트 접속 후 본인의 지갑 주소 입력

- [Sepolia PoW Faucet](https://sepolia-faucet.pk910.de/) — 채굴 방식, 로그인 불필요
- [Google Cloud Faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia) — Google 계정 필요, 소량 즉시 지급

**MetaMask에서 Sepolia 네트워크 추가하는 방법**:
1. MetaMask 상단 네트워크 선택 → "네트워크 추가"
2. "테스트 네트워크 표시" 활성화
3. Sepolia 선택
