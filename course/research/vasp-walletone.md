## 2. 서비스 현황

### 2-1. 주요 제품 라인업

#### OCTET (옥텟) — 기업용 지갑 인프라 플랫폼

- **대상 고객:** 금융기관, 핀테크, 게임사, NFT 플랫폼 등 기업
- **핵심 기술:** 멀티시그(Multi-Signature) + MPC(다자간연산) 기반 지갑 관리
- **주요 기능:**
  - 기업용 멀티시그 지갑 구축 및 입출금 시스템
  - NFT 발행·관리 (민팅, 전송, 소각)
  - 스테이킹 시스템 구축
  - KYC/AML 기능 통합 지원
  - 실시간 모니터링 콘솔 (`console.octet.build`)
  - API 기반 멀티체인 단일 인터페이스 제공
  - STO(증권형 토큰) 플랫폼 지원
  - 옥텟 스테이블 월렛 (결제 특화, USDC·USDT 지원)
- **보안 모델:** 키 분산 보관 옵션 — 키 수탁(Custodial) 또는 고객 자체 보관(Non-custodial) 선택 가능
- **배포 시간:** 2주 내 입출금 시스템 구축 가능 (고객 사례 기준)

#### O-HI WALLET (오하이 월렛) — 소비자용 가상자산 지갑

- **대상 고객:** 개인 사용자
- **가입자 수:** 약 17만 명 (국내 최다 개인 가상자산 지갑 사용자 기반, 2026년 기준) ⚠️
- **특징:** 웹뷰(WebView) 통합으로 기존 뱅킹 앱에 임베드 가능
- **연동 사례:** 신한은행 쏠(SoL), IBK기업은행 앱
- **VASP:** 이 브랜드명으로 금융정보분석원 VASP 신고 수리

### 2-2. 수탁 서비스 기술 방식

| 기술 | 지원 여부 | 비고 |
|------|-----------|------|
| Multi-Signature | ✅ | 핵심 기술로 명시 |
| MPC (다자간연산) | ✅ | 공식 홈페이지 명시 |
| HSM (Hardware Security Module) | ❓ | 공개 문서에서 명시 없음 — 직접 확인 필요 |

## 5. Travel Rule 대응

| 항목 | 내용 | 확인 여부 |
|------|------|-----------|
| TRISA 지원 여부 | ❓ 미확인 | ❓ |
| VerifyVASP 지원 여부 | ❓ 미확인 | ❓ |
| CODE 지원 여부 | ❓ 미확인 | ❓ |
| 특금법 §8의4 대응 | VASP 신고 완료 자체가 특금법 의무 이행 | ✅ |

> **설명:** 월렛원(오하이월렛)은 VASP 신고 수리를 받은 지갑 사업자이므로 특금법 기본 의무는 충족함. 그러나 공개 소스에서 TRISA, VerifyVASP, CODE 등 특정 트래블룰 프로토콜 채택 여부를 확인할 수 없었음.
>
> **교보 프로젝트 관련:** 트래블룰 준수가 필요한 경우 반드시 헥토월렛원에 직접 확인 필요. 기업용 OCTET 플랫폼의 경우 B2B 수탁 서비스 특성상 트래블룰 의무 범위가 다를 수 있음.
