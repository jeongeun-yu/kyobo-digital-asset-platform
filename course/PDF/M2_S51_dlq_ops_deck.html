재큐잉(requeue) 판단 기준

WHEN TO REQUEUE — THREE CONDITIONS, ALL MUST BE MET

조건 판단 근거 (_reason 확인) 조치 순서
일시적 외부 장애 timeout / connection refused 외부 서비스 복구 확인 → requeue
코드 버그 수정됨 배포 이력 확인 + 테스트 통과 확인 배포 완료 후 requeue
데이터 정정 완료 관련 시스템에서 정정 완료 확인 정정 확인 후 requeue
requeue 전 3가지 확인 — 셋 다 YES여야 requeue 가능
①
processed_events에 같은 txHash가 없다
있으면 → 이미 처리됨 → drop 대상
②
실패 원인이 해소됐다
장애 복구 / 코드 배포 / 데이터 정정
③
requeue하면 성공할 근거가 있다
추측이 아닌 확인된 사실
하나라도 NO → requeue 금지. 원인 해소 후 재판단하거나 drop을 검토한다.

드랍(drop) 판단 기준

WHEN TO DROP — FOUR CONDITIONS, ANY ONE IS SUFFICIENT

조건 판단 근거 주의사항
이미 원장에 반영됨 processed_events에 동일 txHash+logIndex 존재 멱등성 처리 완료 — drop 안전
파싱 불가 메시지 _reason에 JSON parse error / unknown field 발신 시스템에 포맷 오류 통보 필수
TTL 초과 이벤트 발생 시각 기준 N시간 초과 금융 이벤트는 TTL 길게 설정 권장

requeue API — 원장 확인 + 감사 로그 필수

REQUEUE WITH LEDGER GUARD AND AUDIT TRAIL

async requeue( dlqId: string, operator: string, reason: string, ): Promise<{ newMessageId: string }> { // 1. DLQ에서 메시지 확인 const items = await this.dlqHandler.listPending(); const target = items.find(i => i.messageId === dlqId); if (!target) throw new Error(`DLQ 메시지 없음: ${dlqId}`); // 2. 이미 원장에 반영됐는지 확인 (drop해야 할 케이스 방어) const txHash = target.event['txHash']; if (txHash) { const alreadyProcessed = await this.db.query( `SELECT 1 FROM processed_events WHERE tx_hash = $1 LIMIT 1`, [txHash], ); if (alreadyProcessed.rows.length > 0) throw new Error('이미 원장에 반영됨. requeue 대신 drop을 사용하세요.'); } // 3. 재큐잉 실행 const result = await this.dlqHandler.requeueMessage(dlqId); // 4. 감사 로그 기록 (운영 행위는 반드시 추적) await this.auditLog.append(operator, 'DLQ_REQUEUE', dlqId, { ...result, reason }); return result; }
원장 확인이 requeue 내부에 있는 이유 — 운영자가 확인을 생략하는 실수를 API 레벨에서 차단. drop해야 할 메시지를 실수로 requeue하면 원장 오염.

DROP WITH MANDATORY AUDIT LOG — IRREVERSIBLE OPERATION

async drop( dlqId: string, operator: string, reason: string, ): Promise<void> { const items = await this.dlqHandler.listPending(); const target = items.find(i => i.messageId === dlqId); if (!target) throw new Error(`DLQ 메시지 없음: ${dlqId}`); // 드랍 전: 전체 페이로드 감사 로그에 백업 await this.auditLog.append(operator, 'DLQ_DROP', dlqId, { reason, originalEvent: target.event, // 전체 페이로드 보존 originalReason: target.reason, failedAt: target.failedAt, }); // 실제 삭제 await this.dlqHandler.drop(dlqId); } // DLQHandler.drop() (S11에 추가) async drop(dlqMessageId: string): Promise<void> { const deleted = await this.redis.xdel( this.dlqStreamKey, dlqMessageId ); if (deleted === 0) throw new DLQMessageNotFoundError(dlqMessageId); }
