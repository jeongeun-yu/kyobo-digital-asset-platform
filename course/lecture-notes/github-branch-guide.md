# GitHub 브랜치 생성 안내

실습 전 본인 브랜치를 아래 순서대로 만들어주세요.

## 순서

```bash
# 1. 레포 클론 (최초 1회)
git clone https://github.com/coincraft12/kyobo-digital-asset-platform.git
cd kyobo-digital-asset-platform

# 2. 본인 브랜치 생성 (이름 영문으로)
git checkout -b student/yourname
git push -u origin student/yourname
```

브랜치명 예시: `student/hongildong`, `student/kimcheolsu`

## 실습 흐름

1. 실습 코드 작성
2. 커밋 & 푸시
3. 완료 후 master로 PR 오픈
